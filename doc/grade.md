# Ожидаемые баллы

Документ описывает ожидаемую оценку по заданиям 1 и 2 для проекта
`mlops-vehicle-insurance`.

Участник команды: владелец репозитория.

## Задание 1 (макс. 57 баллов)

### 1. Сбор данных (макс. 10 баллов)

| Пункт | Статус | Баллы | Пояснение |
|---|---|---:|---|
| Разделение на батчи и эмуляция потока | Готово | 1 | `src/mvp_pipeline.py`: данные читаются батчами через `pandas.read_csv(..., chunksize=batch_size)`, позиция потока хранится в `artifacts/state.json`. |
| Хранилище сырых данных: файловая система | Готово | 1 | Каждый обработанный батч сохраняется в `raw_store/batch_XXXXX.csv`. |
| Расчет метапараметров | Готово | 2 | Для каждого батча сохраняются timestamp, имя файла, индексы файла/чанка, число строк и колонок, общее число пропусков и доля пропусков в `artifacts/data_meta.jsonl`. |
| Конфигурационный файл YAML | Не реализовано | 0 | Отдельных YAML-конфигов в задании 1 нет; параметры задаются через dataclass `Config`, CLI-аргументы и env-переменные. |
| Система логирования и обработки ошибок | Готово | 1 | В `run.py` есть обработка исключений с выводом в `stderr`; в CI лог обучения сохраняется в `artifacts/training.log`. Полноценный `logging`-модуль с отдельными уровнями логов не внедрен. |
| Интеграция с несколькими источниками данных | Готово | 1 | Используются два CSV-файла из `data/`: `motor_data11-14lats.csv` и `motor_data14-2018.csv`. |

### 2. Анализ данных (макс. 10 баллов)

|---|---|---:|---|
