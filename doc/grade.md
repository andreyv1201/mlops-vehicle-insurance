# Ожидаемые баллы и статусы реализации

Документ подготовлен для проверки задания 2. Проект выполняется как продолжение
MVP из задания 1: ML-система обработки потоковых данных для прогнозирования
страховой премии автомобиля.

Участник: владелец репозитория.

## 1. Функциональность workflow

| Пункт | Баллы | Статус | Реализация |
|---|---:|---|---|
| Автоматическое выполнение при push/pull request | 1 | Готово | `.github/workflows/mlops-ci.yml`, секции `push` и `pull_request` |
| Корректная установка окружения | 1 | Готово | `actions/setup-python@v5`, `pip install -r requirements.txt` |
| Успешное обучение модели | 1 | Готово | шаг `Train model on next streaming batch`, команда `python run.py --mode update` |
| Управление инкрементальным обучением из YAML-файла | 1 | Готово | переменные `MLOPS_BATCH_SIZE`, `MLOPS_BATCHES_PER_UPDATE`, `MLOPS_MODEL_CANDIDATES`, `MLOPS_RANDOM_FOREST_ESTIMATORS` |
| CI/CD с инкрементальным дообучением по расписанию на основе предыдущих запусков | 3 | Готово | секция `schedule`, восстановление и сохранение состояния через `actions/cache` для `artifacts/`, `raw_store/`, `models/`, `reports/` |
| Тесты ML-системы средствами CI/CD | 1 | Готово | шаг `Run tests`, команда `pytest -q`, тесты в `tests/test_mvp_pipeline.py` |
| Иное расширение workflow | 0 | На этапе планирования | Возможное расширение: отдельные параллельные jobs для тестов и обучения или интеграция с внешним хранилищем данных |

Ожидаемый результат по разделу: 8 из 8 баллов по основным и реализованным
дополнительным пунктам.

## 2. Управление артефактами

| Пункт | Баллы | Статус | Реализация |
|---|---:|---|---|
| Сохранение логов обучения моделей | 1 | Готово | `artifacts/training.log`, загрузка через `actions/upload-artifact` |
| Сохранение сериализованной модели, допускающей запуск извне | 1 | Готово | `models/model_vXXX.joblib`, `models/registry.json` |
| Сохранение модели/состояния сборщика данных для загрузки актуальных данных извне | 1 | Готово | `artifacts/data_collector_state.joblib`, `artifacts/state.json` |
| Сохранение dashboard истории обучения или запуск онлайн-сервиса на GitHub Actions | 3 | Готово | `reports/summary_latest.json` как summary истории батчей, качества данных и версий моделей; файл публикуется как CI artifact |

Ожидаемый результат по разделу: 6 из 6 баллов.

## Итого

Ожидаемый максимум: 16 из 16 баллов.

Основные реализованные файлы:

- `.github/workflows/mlops-ci.yml` - CI/CD workflow.
- `run.py` - CLI-точка запуска MVP pipeline.
- `src/mvp_pipeline.py` - потоковый update, data quality, обучение, registry и артефакты.
- `scripts/generate_sample_data.py` - генерация sample data для воспроизводимого CI.
- `tests/test_mvp_pipeline.py` - тесты полного цикла update/summary/inference.
